# Embedded C Training Lab

Welcome to **Embedded C Training Lab** — a hands-on learning repository where I (Nafiz Ahamed) explore and master **Embedded C programming** through practical projects on the **STM32F103C8 (Blue Pill)** microcontroller.

This repository follows a structured roadmap designed to build strong **firmware engineering skills** from the ground up — starting from core C programming to register-level coding and modular driver development.

---

## 🎯 Learning Goals

- Strengthen **Embedded C fundamentals** (bitwise, pointers, structs, volatile, etc.)
- Understand **MCU memory and register-level programming**
- Configure STM32 peripherals **without HAL or libraries**
- Write **modular, reusable driver code**
- Build a solid foundation for **RTOS**, **IoT**, and **device driver development**

---

## 🧩 Weekly Learning Outline

| Week  | Focus Area              | Key Topics                                         |
| ----- | ----------------------- | -------------------------------------------------- |
| **1** | C Fundamentals          | Data types, bitwise ops, pointers, volatile, const |
| **2** | Bit Manipulation & GPIO | LED toggle using registers, bit macros             |
| **3** | Memory & Structs        | Memory mapping, storage classes, register structs  |
| **4** | Modular Firmware        | Header/source separation, custom GPIO driver       |
