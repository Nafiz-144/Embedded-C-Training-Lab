What is mask?
Mask means selecting specific bit with a pattern
uint8_t reg = 0b11010110;
uint8_t mask = 0b00111100;
uint8_t result = reg & mask; // শুধু মাঝের ৪টা বিট থাকবে
what is feild ?
Two or more bit work together(like stm(mode:cnf(Configuration)))
Many STM32 registers have multiple bits that make up a field.
For example, the GPIOx_CRL register has 4 bits for each pin, MODE[1:0] and CNF[1:0].
#define FIELD(width, pos) (((1u << (width)) - 1) << (pos))
